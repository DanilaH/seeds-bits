# Данные и разрешения для карточки RuStore

Пакет: `com.seedsbits.game`. SDK: AppMetrica 8.6.0 и Yandex Mobile Ads 8.5.0. Декларация относится к Android-сборке с боевой рекламой; отсутствие регистрации не означает отсутствие сбора данных SDK.

| Раздел в анкете | Что указать и почему |
|---|---|
| Идентификаторы | Да: идентификаторы устройства/установки и рекламный идентификатор при его доступности. Аналитика, реклама, измерение и предотвращение мошенничества; передаются Яндексу. |
| Взаимодействие с приложением / другие действия | Да: сеансы, открытие/начало/завершение партий, использование подсказок и события рекламы. Аналитика и измерение рекламы; передаются Яндексу. |
| Отчёты об ошибках / диагностика | Да: AppMetrica и события ошибок игры/рекламы. Диагностика и улучшение стабильности; передаются Яндексу. |
| Приблизительное местоположение | Учесть определение региона по IP. Доступ к координатам Android не запрашивается; LocationTracking AppMetrica выключен. Не обозначать IP-географию как точное GPS-местоположение. |
| Точное местоположение | Нет: нет FINE/COARSE_LOCATION и передачи координат из игры. |
| Имя, email, телефон, ID аккаунта, платежи | Игра не запрашивает и не передаёт. Обращения в поддержку — отдельное добровольное действие пользователя на GitHub/в магазине, не внутриигровая форма сбора. |
| Фото, видео, микрофон, контакты, календарь, файлы пользователя | Нет. Внутриигровой календарь — список задач, не доступ к календарю Android. |
| Локальный прогресс | Хранится на устройстве. Поля, полные сохранения и отдельные нажатые цифры не отправляются в пользовательские события. Облачного сохранения нет; Android backup отключён. |

Учитывать данные SDK даже если консоль не выбрала их автоматически по разрешениям. Не ставить «данные не собираются / не передаются». Внутриигрового переключателя отключения аналитики нет: параметры необязательности в анкете должны отражать это поведение, а не только возможности SDK.

Нет регистрации, встроенных покупок и пользовательского чата. Реклама — есть; видео за подсказки добровольные. Возрастную маркировку выбрать по анкете с учётом сторонней рекламы; игра не предназначена специально для детей.

Конкретный объединённый manifest и права проверены в `docs/releases/1.0.0-apk.json` после сборки. Обычные разрешения INTERNET, ACCESS_NETWORK_STATE, VIBRATE, AD_ID и получение install referrer объясняются сетью SDK, вибрацией, рекламой и атрибуцией установки. Динамическое разрешение с префиксом пакета используется AndroidX для безопасной регистрации receivers и не предоставляет доступ к пользовательским файлам.
