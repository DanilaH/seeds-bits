# Семечки — feel, 9 ноября 2026

Одобрен весь проход по независимому разбору: общие перелёты/заполнение банок во всех режимах; ограничение анимаций видимой областью; точная подсветка отменённых пар; нажатия цифр без движения сетки; подсказка/отмена/добавление/переключатели; однократный результат, награда серии и переходы. Пользователь дополнительно просит ощутимую вибрацию и ориентироваться на «Дороги», включая кнопки и выбор клеток.

Источники: Road Lines `180d5b1dc4de2687da670a3b6cfc140a0a8fa156`, `src/presentation/feedback.ts`, `native/android/RoadFeedbackPlugin.java`. Kit `a9325265e87583a4872cf6a158e1e881a0d7508e`: `docs/API.md`, Android feedback reference boundary и value-transfer. Готового универсального haptics runtime в API kit нет: адаптируем проверенный нативный рецепт Road Lines с собственными профилями и усиленным барьером отмены. `src/vendor/mini-games-kit/value-transfer.ts` — неизменённый выбранный исходник указанного kit, без новой npm/Phaser-зависимости.

Контракт: постоянный прогресс принадлежит модели и сохранению, анимация только показывает уже начисленное. До успешного сохранения победы не запускать торжественный отклик. Пропуск/фон/навигация/ротация догоняют визуальный счётчик без позднего звука и вибрации. После прерывания не воспроизводить прошлую победу. Новые установки получают включённую вибрацию; сохранённое false сохраняется. Звук остаётся отдельной настройкой с коротким примером включения.

Нативная вибрация: проверять поддержку мотора/амплитуды, Android API24/26/31, foreground, enabled, свежесть issuedAt и монотонную эпоху. Отмена меняет эпоху: запоздалый pulse не должен включать мотор обратно даже в пределах окна свежести. Обычные контакты ограничиваются по частоте без очереди, более важный отклик может заменить менее важный; победа защищает свой рисунок от мелких контактов. Кнопка/клетка/пара/отмена/подсказка/прилёт/полная банка/победа различаются. Несколько наград одного результата используют один главный торжественный haptic.

Проверять: точность количества после всех прилётов и clear; граница полной банки и ARIA; отсутствие повторных наград/побед; быстрые касания и отмена; visible-only и bounded animations на 900/1800 клетках; reduced motion; выключенный звук/вибрация; отмена при рекламе/фоне/навигации; сохранения и явные отключения; нативный cancel/pulse reorder и API fallback. Новая подпись совпадает с опубликованной игрой. Визуальные изменения показать GIF/MP4; нативную силу на физическом телефоне не выдавать за проверенную браузером/CI.
