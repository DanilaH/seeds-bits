# Status — 9 November 2026

По сообщению владельца, 1.0.0 опубликована в RuStore. Выдан обновлённый подписанный APK 1.1.0 (**1100024**), 5 501 048 байт, с тем же пакетом и сертификатом. Он заменяет выдачу 1100023: сохраняет новое оформление медалей и исправляет обрезание нативного поля времени напоминания. Выданы 16 свежих магазинных скриншотов и полностью переснятые GIF/MP4. В магазинном оформлении дополнительно укрупнены и сокращены подписи, проверены уменьшенные превью; мелкая статистика читается при открытии кадра.

Нативная вибрация адаптирована из Road Lines: девять отдельных рисунков, защита от запоздалых вызовов и повторов, приоритет победы. Для отсутствующей настройки вибрация включена; сохранённое false остаётся выключенным. Добавлены явные состояния нажатия без изменения hit area, короткие переходы, точная подсветка отмены и ограничение анимаций больших полей. Награды тетрадей/дейликов летят в общую банку; заполнение показывает 100% перед следующей банкой. Победный отклик однократный и следует после успешного сохранения.

Счётчики подсказок/добавления вынесены в отдельные значки; подпись банки сохраняет геометрию при 100% и смене банки. Исправлены колонки действий в горизонтальной тетради, переносы классики, увеличенный текст и полная видимость основной кнопки результата с двумя наградами. В результате, календаре и у каждого месяца коллекции — одна крупная медаль. На 7/14/всех днях видна полученная ступень; следующая задача показывает заполнение следующего металла. Предыдущие ступени остаются в подписи. Крупная медаль заменяет зелёный круг результата. Новая ступень даёт заметный pop, блик и 32 белых/цветных прямоугольника, ромба и полоски после успешного сохранения. Получение отмечено отдельным контрастным значком. Рядом видны силуэт следующей медали и число оставшихся задач; после золота — сообщение о полной коллекции месяца.

По уточнению владельца от 9 ноября напоминание включено по умолчанию для новых установок и настроек без поля reminders; сохранённое false не переопределяется. При отсутствии разрешения Android однократный запрос следует после сохранённого прохождения сегодняшнего дейлика или по кнопке в настройках. Отказ выключает настройку; автоматически повторно не спрашиваем. Время по умолчанию — около 12:30 по местному времени с возможностью изменения и отключения.

## Historical status — 0.2, 15 October 2026

The following is a historical record for version 0.2; its dependency, release and verification statements do not describe the current published app.

Implemented all three agreed work packages: core interaction/UI polish, 24 notebook tasks in four pages, and daily calendar with monthly bronze/silver/gold trophies. See VERSION_02.md for scope, calendar semantics and limitations.

Local verification: TypeScript and production build passed; 13 unit/property tests passed, including all 24 notebook solution paths and daily solutions across four months (including leap February). Ten Chromium browser scenarios passed: onboarding, lessons, rules/undo/restore, persistent hints, offscreen pair navigation, notebook page completion, classic/task isolation, daily completion/restoration, future-date lockout, bronze collection and calendar layout at 320/360/390/430 px. Screenshots inspected for light/dark game, notebook, calendar, menu and bronze trophy.

Browser tests run with an explicit local Chromium executable when SEEDS_CHROMIUM is provided; CI installs Playwright's matching Chromium. Native debug build and Yandex package are generated by GitHub Actions. Android device behavior, live Yandex SDK integration, iOS build/signing and real-user difficulty/retention are not verified. Daily tasks are deterministic locally and mathematically solvable, not manually playtested for every future date. Trophy checks use controlled progress fixtures; no fixture completion is shipped to players.

Web remains TypeScript/Vite/DOM/CSS/SVG. No React, engine, external font, account, backend, ads or payments. Native app icon/splash/signing still need release preparation. The 1,800-cell classic guard is provisional; it does not declare defeat.
