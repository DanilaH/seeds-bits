# Calm game iteration — 2026-10-17

Intent: a familiar number puzzle that can be played briefly or for a long session without pressure.

Implemented: separate opaque home screen, resume context, three clear mode entries, dedicated settings, full-height notebook/calendar/collection surfaces; light and dark sage/graphite palette; stable compact-puzzle vertical offset and six page marks; hidden add action in puzzles; quieter results with optional statistics; direct restart from a dead end; slightly varied quiet pair tone. Desktop uses a bounded reading/game surface rather than oversized cells. No new modes or economy. Existing save identifiers and boards are unchanged.

Verification: production web and Yandex builds; 13 rule/content tests; 11 browser scenarios, including home obscuring the game, settings navigation, replay, classic persistence, tutorial, hints spanning long fields and reduced motion. Collection layouts checked at 320, 360, 390, 430, 768 and 1366 px. Browser screenshots in preview-v3.

Content audit: 200 deterministic random legal playthroughs per puzzle, seed 42, across 24 notebook puzzles and all 31 October daily puzzles. This is a measure of dead-end sensitivity, not human difficulty or enjoyment. Notebook 1–3 and 6 had 100% completion in this sample; task 22 had 17%, 19–21 had 37.5–42.5%; task 23 was easier again at 72%. Daily October 18 had 16%, October 2 had 19.5%. Retained published boards to preserve started games and stored solutions; added a discoverable recovery action. Human playtesting is still required before rebalancing/versioning content.

Limits: no real-phone tactile/audio assessment, no measured 20-minute comfort result, no proof of retention. Android and platform-hosted behavior require the corresponding build/device checks.
