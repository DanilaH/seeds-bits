## Подсказка

98 легальных альтернатив на 15 полях из аудита, для каждой есть независимо сертифицированное продолжение. В старом Chromium реальный `createSolver` и приложение через Web Worker выдали 76 FOUND и 22 UNKNOWN. В новой версии оба пути выдали 98 FOUND и 0 UNKNOWN в этой выборке. Тест повторяет выигрышный суффикс из аудита и отдельно проходит до конца по подсказкам нового решателя.

На полях с большим исходным количеством цифр решатель восстанавливает исходные индексы клеток по сохранённым ходам с учётом удаления строк. Он сохраняет легальные пары из известного решения, при необходимости оставляет первую пару исходного решения для разбора остатка и решает остаток в пределах 256 узлов из общего бюджета. Результат возможен только при полном проверенном продолжении. Если история недоступна или перестройка не помогает, работает прежний ограниченный DFS. Суммарные лимиты 2 000/50 000 и таймер 2 500 мс прежние. UNKNOWN сохраняется, в том числе у позиции `book-v1-1821` после `[2,3]` при удалённой истории. На нём нет списания. Подтверждённый тупик проверяется отдельно.

| Выборка 98 позиций | FOUND | UNKNOWN | `createSolver`, p50 / p95 | Worker с запуском, p50 / p95 |
| --- | ---: | ---: | ---: | ---: |
| PR №21 | 76 | 22 | 2,4 / 38,3 мс | 17,2 / 83,1 мс |
| После доработки | 98 | 0 | 1,9 / 8,8 мс | 47,0 / 160,1 мс |

Это два локальных прогона Chromium headless shell с отдельным запуском воркера на каждое поле. На втором параллельно выполнялись другие проверки. Время воркера включает планирование и загрузку его модуля, поэтому по этому замеру нельзя сравнивать задержку на телефоне. | 5–8 | 16, 12, 16, 18 | MODERATE, FLOW, FLOW, MODERATE. Проигрышные выборы появляются позже старта |

Полный граф нового набора — 15 664 состояния, 102 выигрышных, 1 проигрышное и 0 непроверенных стартовых действий. До правки — 114/6/0. В старой №3 проигрывала `[9,11]`. В старой №9 — `[12,16]` и `[18,19]`. У обеих новых задач полный граф без проигрышных состояний. Те же шесть политик аудита дают 49/72 выигранных партий до, 66/72 после. Для №3 результат изменился с 1/6 на 6/6, для №9 с 0/6 на 6/6. Это модель игровых действий.

№1 и №2 сохранены. Слот 2 требует хотя бы один переход через край на каждом выигрышном пути. Контрольный маршрут из паспорта доводит до пары `[3,14]`, пока исходный текст-подсказка виден до нажатия. Проверка проходит на чистом профиле при доступных парах, без блокировки ходов. Паспорта приводят поля в девять колонок, плотность, геометрию, полный выигрышный replay и причинные эпизоды. Новые раскладки проверены на нормализованные дубли и совпадения формы с фиксированными банками v1/v3/v4/v5. [Паспорта](opening.json).

## Сохранения и воспроизведение

Слоты 3–12 получают ревизию 6 только при первом назначении. Закреплённые v1/v4/v5 остаются привязаны к своим раскладкам. Вторая задача сохраняет существующую v5. Опубликованные банки, ежедневные даты, Классика и формулы наград остались на прежних версиях. Wire10 записывается только при наличии пина ревизии 6. Предыдущая запись сохраняется при первом переходе. Повтор решённого логического слота использует прежнюю раскладку и не начисляет награду второй раз.

```sh
node scripts/check-opening-revision.mjs --json
npm test
npx playwright test e2e/hint-repair.spec.ts e2e/content-v5.spec.ts
npx playwright test --config playwright.first-session.config.ts
```

Для времени запустите Vite в отдельно проверяемом checkout и передайте его адрес в `node scripts/measure-notebook-hints.mjs URL output.json` из этого PR. Браузерный сценарий исходной версии повторяется с `SEEDS_BASELINE_HINT=URL` и фильтром `-g 'audited alternative'`.

Плейтест новичков на телефоне, активные семечки/мин для 8–26, 28–54, 56–108 и Классики остаются UNKNOWN. Для замера нужен физический запуск этих режимов с активным игровым временем и реально начисленными семечками. KIT IMPACT — REUSE. Использованы полный граф выбора, свидетельство решения и отдельная неизменяемая ревизия.
