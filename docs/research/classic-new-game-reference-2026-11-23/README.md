## Reference → product porting

| Что взяли / сознательно не взяли | «Семечки», режим Классика | Parity и следующий шаг |
|---|---|---|
| Раздельные `Продолжить` и `Новая классика` | `src/main.ts:renderHomeCurrent` оставляет текущую партию, `#next-classic` открывает самостоятельный выбор уровня из любого режима. Кнопка входа в существующую классику `#classic-mode` не заменена; `switchGame` сохраняет старые сценарии | **PARTIAL / функциональная адаптация**: в Cross Math New Game относится к его основной игре, у нас CTA честно называется «Новая классика» |
| Компактная нижняя панель, быстрый выбор | `src/main.ts:classicNewSheet/renderClassicNewSheet/openClassicNewSheet`, `src/calm-screens.css:#classic-new-sheet`, `src/i18n/ui-copy.json`. Три интерактивные строки не ниже 44px, закрытие крестиком, Back/Escape и касанием фона. Фон меню сохраняется под модальной панелью | **PARTIAL / намеренное отличие:** перенесён паттерн, но собственная палитра, пиктограммы, тексты; исходных чужих ассетов нет |
| Диапазоны сложности | Использованы только текущие, подтверждённые `src/classic-generator.ts` уровни `0/1/2`: **18 / 28 / 27 цифр**, без нового алгоритма. Выбор из незавершённой классики проходит через существующую `requestRestart("next", level)` и подтверждение. Из другого режима вызывается `beginClassic("next",level)` с сохранением `sessions[oldActive]` и Undo | **MATCH по обещанию наших уровней; INTENTIONAL DIFFERENCE** с 4 уровнями референса. «Эксперт» — DEFERRED до отдельного решения владельца и испытаний генератора |
| Подготовленное поле и таймер | Наша классика без таймера и без искусственной стартовой паузы. Выбор генерирует поле и сразу даёт касаться цифр | **INTENTIONAL DIFFERENCE**, экономит один лишний тап и не вводит новую политику времени |
| Daily Completed и событие/Endless | Наши дневные задачи уже показывают статус и сохраняют возможность повторного запуска без повторной награды. Отдельные countdown, event-currency и дублирование Endless не добавлены | **DEFERRED/UNKNOWN**: перед усложнением меню нужен отдельный дизайн/плейтест; нельзя выводить экономику из видео |
