## Подсветка достижимости

Прямое решение владельца: при выборе цифры слегка выделять цифры, до которых она может дотянуться. `core.ts:reachableNumbers` возвращает первую занятую клетку по каждому из восьми направлений и соседей в порядке чтения. Промежуточные пустоты разрешены, занятые клетки блокируют луч. Значения цифр не отбирают кандидатов: это видимость, а не обещание подходящей пары.

`board-view.ts` сохраняет DOM-узлы; выбор, снятие выбора, удаление пары, сжатие строк, Undo и Add обновляют подсветку. Подсказка и выбранная цифра имеют визуальный приоритет. Сейв, баланс, стоимость подсказок, награды и все шесть приостановленных экспериментов не меняются. В пошаговом обучении новый слой не показывается, чтобы сохранить адресные инструкции урока.

Приёмочный пример: поле длиной 45, остальные клетки нули, значения `{0:4,2:1,4:6,8:6,9:2,10:3,20:8,44:4}`. Нажать 0: подсветить **2, 9, 10**, не подсвечивать 4 и 20 за препятствиями. Повторное нажатие снимает подсветку. Значения 1/2/3 не образуют пару с 4; это намеренное различие геометрии и правила значений.
