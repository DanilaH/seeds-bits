## Что это означает для новичка

Фраза меняется по мере действия. В первой задаче игрок видит «Нажмите любую цифру», затем подсказку про пустые клетки, а перед последней парой — объяснение перехода через край. Победа предлагает конкретную задачу 2. В русской версии при 200% текст о крае уместился, пара осталась доступна; универсального перекрытия поля или скачка при каждой подсказке в этом проходе не обнаружено.

Смысл режимов сейчас вводится главным образом в меню. Там у тетрадей написано «Сборники по 24 задачи», у задачи дня — «Новое поле каждый день». После первой победы игрок может перейти прямо в задачу 2 и обеих подписей вообще не увидеть. Это объясняет, где проверить наблюдение владельца. Данных о доле растерявшихся игроков и влиянии на удержание этот аудит не даёт.

Для проверки с тремя новичками достаточно одного короткого сеанса на человека. После первых двух пар предложить найти следующую самостоятельно, после первой победы попросить объяснить своими словами, что такое тетрадь, затем найти задачу на сегодня и снова открыть оставленную тетрадь. Записать первое действие, место остановки и понадобилась ли подсказка ведущего. Если путаница в режимах повторится, самый дешёвый эксперимент — одна строка после первой победы, например «Это первая из 24 задач тетради. Продолжить можно в любой день». Приёмка этой гипотезы — понимание и самостоятельный возврат игрока.
