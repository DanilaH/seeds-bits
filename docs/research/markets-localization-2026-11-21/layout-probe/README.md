# Первый сеанс и календарь на десяти языках

Исследование 21 ноября 2026 года. В «Семечках» на узком экране длинная команда могла заканчиваться ниже видимого края своей панели. На исходной редакции это воспроизвелось в 33 из 320 комбинаций. Подготовлены короткие варианты трёх команд и 11 недостающих строк реального игрового пути. В повторном прогоне все 360 комбинаций поместились. [Каталог переводов](../launch-copy.json) · [Измерения](./measurements.csv)

## Что именно проверено

- Собрана веб-версия из игровой ревизии `145a5124` (исходники preview 12066), с первым сеансом и обычной помощью. В headless Chromium 141.0.7390.37 реальными нажатиями пройден путь от чистого профиля через ошибку и подсказку до победы в тетради, задачи 2, выбора тетради, календаря и задачи дня. Первую тетрадь завершали парами с индексами 8/17, 4/5, 9/11, 7/14 при отсчёте с нуля. [Игровой код](https://github.com/DanilaH/seeds-bits/blob/145a512457484f9ffe49ace435883e622dc38934/src/main.ts#L1827) · [Исходный сценарий](https://github.com/DanilaH/seeds-bits/blob/145a512457484f9ffe49ace435883e622dc38934/e2e/first-session.spec.ts)
- При измерении в настоящей панели первой задачи подставлялся перевод текущей команды, устанавливался язык элемента и снимались прямоугольники текстовых строк. Остальной интерфейс продолжал работать на русском. Два размера экрана в CSS-пикселях, имитация занятого мобильного рекламного слота и два размера текста. При 200% применён тот же способ удвоения вычисленного размера шрифтов, что и в браузерном тесте проекта. Системная настройка Android, клавиатура, WebView телефона и полностью локализованный интерфейс требуют отдельной проверки.
- «Не помещается» означает, что часть строки ниже начальной видимой области и игроку нужно прокрутить саму подсказку. Допуск округления — 1 CSS-пиксель. Проверяли верх и высоту игрового окна, а также попадание в центры видимых непустых клеток. Смысл команд для человека проверяется отдельно. [Вёрстка зоны текста](https://github.com/DanilaH/seeds-bits/blob/145a512457484f9ffe49ace435883e622dc38934/src/ui-adaptation.css#L1000) · [Сценарий исследования](./probe.cjs)

| 320×568, 100% | 0 из 80 | 0 из 90 |
| 320×568, 200% | 14 из 80 | 0 из 90 |
| 568×320, 100% | 0 из 80 | 0 из 90 |
| 568×320, 200% | 19 из 80 | 0 из 90 |

Исходная матрица — восемь достигнутых игровых состояний × десять языков × четыре профиля экрана. Дополнительные 40 проверок относятся к команде после первой пары, появившейся в каталоге. На общих 320 проверках результат изменился с 33 случаев до нуля. Наиболее заметный пример — переход через край строки по-немецки в альбомном режиме. Конец прежнего текста был на 69 CSS-пикселей ниже допустимой границы с учётом допуска. На том же поле короткая команда читается целиком. Геометрия игрового окна при замене команд не менялась ни в одном из четырёх профилей. После правки все 2 400 измеренных точек в центре видимых непустых клеток по-прежнему попадали в свои кнопки. Это повторные измерения одних и тех же клеток в разных состояниях. [Немецкий до](./before.png) · [Немецкий после](./after.png)

Изменены только формулировки `open.either`, `error.sum` и `open.edge` на языках, где возникло переполнение. Зависимость команды от легальной пары и выбранной цифры остаётся в игровом коде. **Приёмка разработчику:** подключить обновлённые строки, открыть задачу 1, выбрать 9, допустить ошибку пары и дойти до перехода через край. Проверить на телефоне при шрифте 200%, что игрок видит всю команду до следующего нажатия. Повторить с полностью переведённым заголовком и кнопками. ## L10N-DATE-03 · Выбор месяца на вьетнамском

В текущем русском интерфейсе подпись месяца для выпадающего списка берётся из первой части строки «месяц год» через `.split(" ")[0]`. Проверка на всех двенадцати месяцах показала эффект простой замены локали на `vi`: в каждом пункте было бы написано «tháng». Для ноября полная запись — «tháng 11 năm 2025», а форматирование одного месяца даёт «Tháng 11». Это воспроизведение поведения форматтера на данных нашей сборки. [Код названия месяца](https://github.com/DanilaH/seeds-bits/blob/145a512457484f9ffe49ace435883e622dc38934/src/main.ts#L3274) · [Код выпадающего списка](https://github.com/DanilaH/seeds-bits/blob/145a512457484f9ffe49ace435883e622dc38934/src/main.ts#L3795) · [Все подписи по локалям](./observations.json)

**Приёмка разработчику:** форматировать отдельно заголовок месяца с годом и название месяца для списка через `Intl.DateTimeFormat(locale, {month: "long"})` для второго случая. Значение option сохраняет числовой код месяца. На вьетнамском открыть календарь, выбрать 2025 год, увидеть 12 различных подписей и переключиться между октябрём и ноябрём. Сверить открытые даты и выделение дня. Эту проверку добавить до выпуска B2.

## Воспроизведение

Рабочая копия игровой ревизии `145a5124`, проектные зависимости и Chromium Playwright. Из корня игры собрать `VITE_SEEDS_FIRST_SESSION=1 VITE_SEEDS_QA_PROFILE=baseline npm run build`. Запустить `node /path/to/probe.cjs /path/to/launch-copy.json /tmp/measurements.json`. Сценарий отдаёт локальное содержимое `dist` браузеру и фиксирует дату 21 ноября 2026 года. Через `CHROMIUM_PATH` можно передать установленный Chromium, через `PROBE_SCREENSHOT` задать путь для кадра с немецкой командой. Для сравнения использовать [прежний каталог из ревизии 6a5607b](https://github.com/DanilaH/seeds-bits/blob/6a5607bd28d5f6c0cf2edcc992c470e90f40ac1c/docs/research/markets-localization-2026-11-21/launch-copy.json) и [новую редакцию](../launch-copy.json).

Статус доказательств — исходники, пройденный русскоязычный веб-сценарий, измерение переводов в работающем компоненте и модель локализованного выбора месяца. Открытые проверки — полный локализованный APK на физическом телефоне, понимание коротких команд новичками и фактическое удержание. KIT IMPACT — кандидат после второй игры: сверять название месяца в списке и контекстную команду на реальных данных локали.
