## Как читать контрольный отчёт

[Выгрузка контрольных запусков](./CONTROL_REPORT.json). Период 19–21 ноября 2026, `Asia/Yekaterinburg`, дата отсечения 22 ноября. Включены события QA без моделирования задержки экспорта. Секция `browserSDKDouble` содержит фактические браузерные действия с двойником SDK и контролируемым временем. Секция `syntheticControls` прогоняет заданные входные строки Android и ОК через расчёт отчёта. Эти выборки относятся к двум отдельным запускам проверки.

| Контроль | Результат |
| --- | --- |
| Android | Три штатные строки установки. По одной для RuStore, NashStore и файла с неизвестным магазином. Повтор и обновление не добавили строку новой установки. |
| Яндекс Игры | Один новый веб-профиль с EN → EN, одна первая самостоятельная пара, одна первая задача, D1 1 из 1. Один игрок открыл список трижды, выбор изменился дважды. |
| ОК и GamePush | Один новый веб-профиль с двумя полями источника. Есть контроль смены только Auto ↔ ручной при том же языке. Вход без постоянного хранилища попал в сессии. |

Расчёт принимает JSON `{installations, events}` и JSON настроек `{from, to, asOf, timezone, includeQA, delayMinutes}`. Команда `node scripts/markets/report.mjs export.json period.json`. Для примера без кабинета используйте `node scripts/markets/control.mjs`. По умолчанию QA исключается. Android Install считается по строке выгрузки установок, веб-профиль — по первому интерактивному полю на подтверждённом портале. Повторная доставка события удаляется по идентификатору. D1 использует созревшую когорту и календарный день в выбранной зоне. В знаменатель доли открывших входят активные профили периода, в знаменатель доли изменивших — уникальные открывшие. В контрольных данных нет измерений живой аудитории.

## B1 и B2

Пакет из 120 ключей включает формы множественного числа, он сохранён в `src/i18n/launch-copy.json`. Сборка B1 использует RU, EN, ES, TR, PT-BR. Дополнительные 305 ключей B1 в `src/i18n/ui-copy.json`. На 80 контрольных браузерных экранах B1 проверены первое поле, настройки, самоназвания, политика данных, прогресс, коллекция, календарь и начало полного курса в портрете и альбоме. Отдельно проверены EN → ES, 320×568 и 568×320 при имитации 200%, обе очередности касаний. Проверка включает целый текст, равную геометрию поля до и после подсказки, сохранение выбранной цифры, снятие пары и сохранение Undo.

[B2 UI · редакторский черновик](./B2-UI-DRAFT.json) содержит дополнения для FR, DE, IT, VI и ID. В каждой локали совпадают все 305 ключей и наборы подстановок B1. Перед включением пройти глазами обе темы и обучение, проверить формы, переносы французского и немецкого, диакритику вьетнамского, TalkBack и нативные напоминания. Требуется обновление с B1 с проверкой Auto при `it-IT` и ручного EN.

Вне автоматической приёмки — физический телефон с системным шрифтом 200%, TalkBack, получение переведённого Android-напоминания при закрытой игре, языковая проверка носителями и самостоятельный ход новичка. Нет доступа к тестовым кабинетам и контрольным установкам из клиентов магазинов.

## Настройка тестового размещения

Android. Для файла задаётся `SEEDS_ARTIFACT_CHANNEL` из реестра. Для оформления тестовой AppMetrica установите тестовый ключ приложения, зарегистрируйте строковый атрибут `install_store` и выгрузите Install + Events. Обновления прежней партии относятся к `legacy` или `undetermined` по данным установки. Код использует [Android InstallSourceInfo](https://developer.android.com/reference/android/content/pm/InstallSourceInfo); отчёт использует [выгрузку AppMetrica](https://appmetrica.yandex.com/docs/en/mobile-api/logs/ref/events).

Яндекс Игры. Для приёмки кабинета соберите режим `yandex` с `VITE_SEEDS_YANDEX_APP_ID`, `VITE_SEEDS_YANDEX_TELEMETRY=1` и `VITE_SEEDS_YANDEX_COUNTER`. Создайте JS-цели `web_first_play`, `web_session_open`, `activity_day`, `locale_resolved`, `language_picker_open`, `language_changed`, `first_unassisted_pair`, `first_complete`, `game_start`, `game_complete`. Отдельный ZIP с `VITE_SEEDS_MARKET_QA=1` выдаёт события локально для проверки и подходит для прогона интерфейса. При однозначном размещении `VITE_SEEDS_PORTAL_ORIGIN` должен соответствовать origin этой игры и конкретного портала, а `VITE_SEEDS_PORTAL` и `VITE_SEEDS_DISTRIBUTOR` — строке реестра. Для сборки, где портал из origin определить нельзя, нужен подтверждённый контекст платформы. [Метрика для Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/yandex-metrica) · [Документация GamePush](https://docs.gamepush.com/tutorials/publishing-the-game-on-platforms-guide/)

KIT IMPACT — CANDIDATE. После второго фактического размещения сравнить способы подтверждения и повторной сверки, затем решить, переносить ли шаблон приёмки в кит.
