## Data and method

[summary.json](summary.json), books-1..4.json and daily-365.json contain 2765 immutable rows. Each row: digit string, packed path (alphabet 0–9 A–Z a–z - _, two indices per move), risk profile, actually verified leading role, style index (uniform/clusters/bands/border), digits, rows, safe opening count, all opening count, first witnessed risk step (-1 for flow), proof class, attempts, requested role, visited states. The author uses legal reverse construction and the exact pair/removal functions; graph search rejects unknown first-move outcomes, flow requires all reachable states winning, moderate requires all opening moves winning and a later losing alternative, tactical requires ≥2 safe first moves and ≥40% safe among mixed opening moves. No Add or Undo in proof. Roles verify the actual path (causal reveal, chain, compression, distant connection, mix, competition, flow). 58 of 2765 requested roles changed to an explicitly verified alternate role; no risk profile was relaxed. 57,143 candidates, 23,611 legal witness moves. Authoring exclusion keys and masks: 336 historic eligible short boards, 76 previous designs, 120 v3, 1095 v1 daily dates (2025–2027). Full original-bank comparison is a CI gate, not assumed from the subset. Human difficulty and retention UNKNOWN.

2400 notebook candidates: 800 flow / 1100 moderate / 500 tactical. The first slot is generated but deliberately not activated because it is used for fixed onboarding. Thus 2399 existing unstarted slots can change. 100 original volumes and IDs unchanged; four v3 thematic notebooks remain appended. 365 dates: 139 flow / 174 moderate / 52 tactical, Dec 25 2026 through Dec 24 2027. Earlier date schedules v1 and v3 unchanged. Beyond bank, frozen v4 deterministic eight-candidate selector using variable size/rows and causal witness features with a constructive fallback; not a certified risk profile or a lifetime duplicate guarantee.

Reproduce (read-only): `node scripts/build-content-v4.mjs` on Node 24+. Run `npx vitest run tests/content-v4.test.ts` for full bank replay, canonical/mask gates, old wires, new pins, reward aliases, and sample future dates. Tests added, not yet reported green until CI runs.
