# Меню, тетради и постоянный баннер

[Задача №31](https://github.com/DanilaH/seeds-bits/issues/31) · исходный runtime PR25 `00810143`, preview 12088. Два варианта по 320×568 и 390×844 подготовлены до правок. Взяли сетку с действием над баннером и быстрым входом сбоку.

- Классика после победы ведёт в Home. Выбор новой сложности вынесен в отдельное действие. Припаркованная незавершённая Классика заменяется только после подтверждения.
- Поле, Home, тетради, выбор номера и календарь используют один нижний слот. Допустимость баннера отдельно от игровой паузы. Там, где открывается настоящий модальный экран, view скрывается и сохраняется для возврата. Native принимает только актуальную ревизию с измеренными границами обоих viewport.
- Переходы используют общий рекламный маршрут. Состояние сохраняется до рекламной возможности. Native 180 с, initial grace, общая JS-защита 30 с и отложенный показ после rewarded сохранены.
- Локальный `lastBookTask` относится к ранее открытому полю. Выбор диапазона, фильтра и тома меняет только экран каталога. Для старых сохранений без порядка посещений при нескольких припаркованных партиях используется порядок каталога. Пины и Wire10 остаются прежними.

Проверки: `e2e/menu-package.spec.ts`, `scripts/regression-061/native-harness.py`, `scripts/markets/android.mjs`. Ядро генерации, книги, дейлики и экономика относятся к прежней ревизии. [Контракт баннера «Стрелок»](https://github.com/DanilaH/mini-games-kit/blob/5cac32b0851c80bdff1d61069b8524b9e42170e1/docs/extraction/ARROWS_BANNER_0392.md).

Снимки «до» в Chromium снимаются с web-ресурсов точного подписанного 12088. Снимки «после» и браузерная запись используют новый интерфейс и тестовый мост для проверки места под баннер. Native запись подтверждает только фактически наблюдавшиеся стадии demo SDK. APK, устройство, экранные размеры и границы проверки указываются вместе с артефактами прогона.
