# Воспроизведение повторной проверки GA-01

«Семечки», режим «Классика», preview12082. Это переносимый пакет уже выполненных проверок. Игровых исходников в нём нет; рабочие файлы приложения не изменяются.

## Требования и точные источники

Нужны Node24, git и checkout `DanilaH/seeds-bits`, содержащий оба коммита:

- После исправления: `df9ff5c3df8b017803e2ff924c2812a5efc530ac` (runtime `eae2bcbeaaa1a5c76872dddc7a7f79844988b60e`).
- До исправления: `7f8ac0e05a338d4101d10f680720343b6881ba9a`.

`generator-load.mjs` читает по четыре TypeScript-файла каждой ревизии командой `git show SHA:path`, проверяет Git blob SHA и SHA256 из `MANIFEST.json`, снимает типы и исполняет их в памяти. Незакоммиченные рабочие файлы не используются. Пакет не скачивает источники автоматически, не меняет ветки и не устанавливает зависимости. Полный checkout с нужными объектами должен быть доступен заранее.

## Команды

Из корня checkout игры:

```bash
node docs/research/generator-audit-2026-11-23/followup-12082/ga01-repro.mjs
node docs/research/generator-audit-2026-11-23/followup-12082/bounded-check.mjs
```

При запуске из другой папки укажите абсолютный путь к скрипту и checkout. Например:

```bash
node /path/to/package/ga01-repro.mjs --repo /path/to/seeds-bits --output /path/to/results
node /path/to/package/bounded-check.mjs --repo /path/to/seeds-bits --output /path/to/results
```

Эквивалентные переменные окружения: `SEEDS_AUDIT_REPO` и `SEEDS_AUDIT_OUTPUT`. Аргументы имеют приоритет. По умолчанию результаты пишутся в `test-results/seeds-generator-audit/followup-12082/` внутри указанного checkout; приложенные архивные JSON не перезаписываются.

## Что именно повторяется

- `ga01-repro.mjs`: прежняя серия seed12081, High45, раздачи29/30; полные входы, поля и сертификаты. Дополнительно — уже выполненная причинная проверка влияния штрафа motif при неизменных seed, recent, рецептах истории и пуле кандидатов. Изменяется только исследовательская копия входных метаданных.
- `bounded-check.mjs`: 64 пары свежих выдач до/после, 496 серийных партий, 36 принудительных fallback и 13 сценариев метаданных/миграции. Суммарно 661 replay; перечень seed и все лимиты фиксированы в скрипте. `legacy-inputs.json` содержит компактные исходные состояния двух прежних раздач; зависимости от старого scratch нет.
- `generator-ga01-repro.json` и `generator-bounded-results.json`: сохранённые результаты первоначального исполнения этих проверок на Node v24.22.3. SHA256 приложенных файлов — в `MANIFEST.json`. На той же версии Node повтор выдаёт те же байты; другая версия Node24 может изменить поле `runtime`.

## Упаковочная проверка и границы

Переносимость проверена из посторонней рабочей папки через оба способа выбора checkout: CLI и ENV. Использован временный частичный Git object store с точными закреплёнными commit, root/src tree и нужными blob-объектами. Все их object ID совпали с GitHub; исходники извлекались настоящим `git show`. Полный clone и остальные файлы/история проекта для этой упаковочной проверки не загружались.

Оба выходных JSON побайтно совпали с исходно сохранёнными результатами. Это повтор существующих сценариев для проверки упаковки, не новая выборка и не дополнительные независимые 661 проверки. Пакет содержит только скрипты исследования, входные данные, результаты и manifest.

Результаты относятся к одному сертификату каждого поля и сериализации `ClassicRun`. Они не заменяют UI/Android/физический телефон, человеческую оценку интересности, длительную аудиторию или экономику. Смена recipe и смена центрального мотива учитываются отдельно; жёсткое чередование рецептов не требуется.
