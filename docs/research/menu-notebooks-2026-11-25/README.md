## 2. Предлагаемая информационная архитектура (сохранить calm style)
Home: компактный заголовок без X, карточка незавершённой партии (режим, точный номер/дата, сложность только Classic, CTA Continue), три постоянно видимых режимных действия. Когда нет продолжения — одна основная CTA начать; не подставлять прошлую победу как текущую партию. «Классика» открывает существующий выбор четырёх сложностей; если припаркованная незавершённая Classic, сначала ясное «Продолжить» / «Новая игра»; выбор новой требует подтверждения замены конкретной партии. Restart/replay — вторичное контекстное действие с подтверждением, а не конкурирующий CTA Home. Не удалять режимы/переключатель сложности и выбранную difficulty. «Тетради» → hub. «Задача дня» → текущая дата, «Другие дни» → календарь; не объединять дату и archive alias без проверки. Нижняя служебная навигация (Прогресс/Как играть/Настройки/Язык), above stable banner. На коротком экране сжимать декор, gap, картинку, а не кликабельные цели. Субэкраны имеют единую кнопку Back; реальный confirm/language modal — Cancel/close, не resume.

Catalogue: header «Тетради», карточка конкретного продолжения (одна, не 3 CTA); видимые сегменты «Основные 100» / «Тематические 4», отдельный лёгкий фильтр «Все / В процессе / Решены / Не начаты» применён ко всему выбранному разделу. Основные: 10 диапазонов 1–10…91–100 с понятным переключателем диапазона, предыдущий/следующий, прямой выбор номера или диапазона без скролла 100 обложек. Предложение не делать поиск по тексту/новую currency. Карточка тома: №, progress n/24, статус по фактам; 3–5 колонок в зависимости от ширины, на 320 при необходимости 2–3. Tap → отдельный detail, не переписывать сам каталог. Темы: четыре именованных карточки с простой конкретной подписью («Новые связи», «Важный выбор», «Поле меняется», «Сочетание приёмов»), count 0..24; отдельный таб, никакой дублирующей кнопки. Прогресс main (2400) и themes (96) не путать; общий итог 2496. Не менять content IDs, bank v1/v3/v4/v5/v6 и награды, не считать тему №101 продолжением №100.

Detail: header «Тетрадь №N» или имя темы, 0..24 и progress, кнопка «Все тетради»/Back возвращает к точному каталогу; одна CTA (точная задача) закреплена над баннером или видна в верхней части, не закрывает сетку. Все 24 задачи доступны без accordion; 4 группы по 6 (существующее семантическое завершение страницы); 6 в ряд только при реальной ширине, на 320 сетка адаптируется и scroll внутри content. 4 состояния: новая (номер), начатая (значок/подпись), решена (✓), рекомендованная следующая (контур/текст). Текущая/припаркованная имеет отдельный accessible label; не цвет-only. Повтор решённого доступен, честно обозначить повтор без новой награды. Не скрывать карточку начатой на странице 3/4. Навигация ± том или из каталога, не менять сохранённый active при просмотре. Подбор рекомендованной: последнее незавершённое актуальное/припаркованное поле тома, иначе первая нерешённая, иначе replay выбранной; при нескольких unfinished явный статус и выбор, не подменять ID. Для всей main серии — текущий/последний играемый незавершённый том, затем первый нерешённый основной, все решены → отдельный done state. Не использовать глобальный active для определения последней тетради после Classic/daily. Если persist view preference, это не game identity; в старом сейве вычислить fallback из sessions/done без destructive migration.

Visual acceptance: реальные before/after одного состояния, не только макет.
