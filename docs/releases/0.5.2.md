# 0.5.2 — audit fixes and compact undo history

CI: https://github.com/DanilaH/seeds-bits/actions/runs/39428389187

## Changes

- Landscape hint navigation stays in the scrollable status flow and remains clickable. Long status messages stay inside their grid row. Save errors have one visible warning with a reachable retry button. Enlarged-font and portrait/landscape regressions cover these layouts.
- A failed notebook chunk load removes the loading state and shows an alert inside the open collection. The recovery button saves the current game before reloading; a failed save prevents reload.
- Notebook page completion numbers are local to the volume (1–4). Switching sections retains the selected completion filter and only chooses matching volumes inside that section.
- Trophy months are generated directly for the selected year, removing the old 1,200-month cutoff. Regression covers leap-day navigation and trophies in 2125.
- Rotation clears seed flights so they cannot continue towards obsolete jar coordinates.
- Wire format v4 stores reverse row deltas for undo snapshots. Every historical board, move/addition count and scroll offset is retained. Old v2/v3 saves migrate on write; older builds recognize v4 as a future format. Damaged compact history recovers the valid current board and reports recovery. Other sessions survive.
- Immutable session/history references are retained during transactional mode switching, preserving encoding caches. Failed switches still leave the previous game active.

## Validation

The compact-save fixture contains 100 unfinished notebooks and 6,830 undo entries. Serialization shrank from 5,308,300 to 351,151 characters (93.38%). The regression compares every decoded snapshot and separately traverses complete undo histories, including added numbers, collapsed/repeated/partial rows and branched histories. Timing in the evidence file is a local observation under shared-host load, not a device benchmark.

A browser storage run loaded all 101 sessions (classic plus 100 notebooks), made and persisted a classic move, reloaded, then undid it. All 100 notebook sessions were unchanged and the saved move survived reload. Evidence: `0.5.2-evidence/browser-storage.json`.
