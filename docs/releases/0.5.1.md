# 0.5.1 — results and landscape

Runtime: `74f88320ee1cca8626fc2648872ebcb324781683`; final test-aligned commit: `919470547839eb68e052c87cbee34656bfcfe258`.
CI: https://github.com/DanilaH/seeds-bits/actions/runs/39422249601

Completed games hide the entire move toolbar (undo, hint, add). Result statistics are always visible, without a disclosure. Starting the next game restores the toolbar. The undo handler also ignores a finished board; reward deduplication remains covered by unit tests. Browser tests now exercise undo before completion and the finished-game flow instead of requiring the removed post-win control.

For landscape viewports at least 540px wide and at most 600px high, the board occupies the left column at full available height. Navigation, mode, page progress, feedback and controls sit on the right. The jar has its own header row to prevent label wrapping. Larger desktop/tablet windows retain the centered board and normal readable cell sizes. Tutorial retains its scrollable layout.

Local verification: 18 targeted browser tests passed, followed by all five landscape tests again after final spacing adjustments. Sizes: 568×320, 667×375, 844×390, 1024×600, 1280×800. Tests cover horizontal overflow, readable cell size, full-height landscape board, scrolling to the last row, pair/undo, rotation to portrait and back, visible result statistics, hidden toolbar and starting another game. Additional visual check opened task 2400, used its hint, and inspected light/dark landscape. No browser errors were captured.

Screenshots and local logs are in `0.5.1-evidence/`. Physical Android rotation, cutouts and system navigation insets have not been tested on hardware.

A04 now verifies the requested finished screen and next-party behavior; A13 exercises sound toggles on an unfinished board. Both targeted replacements passed. No runtime change was needed.
