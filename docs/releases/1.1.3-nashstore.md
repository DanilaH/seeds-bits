# «Семечки» 1.1.3 для NashStore

Версия 1.1.3 / 1103101 продолжает опубликованную RuStore-версию 1.1.2 / 1102103. Обе используют `com.seedsbits.game` и один релизный сертификат. Публикация 1.1.3 в NashStore не требует одновременного выпуска в RuStore. При следующем выпуске можно загрузить тот же APK в RuStore или назначить новой сборке `versionCode` выше 1103101. Другой магазин может предложить обновление по правилам установщика и Android.

## Магазин установки

При первом запуске после чистой установки игра определяет магазин через Android PackageManager и сохраняет `install_store`. Поддерживаются `rustore` (`ru.vk.store`), `nashstore` (`com.nashstore`) и `unknown`. Если более ранняя версия не записала исходный магазин, после обновления приложение сохраняет `unknown`. Записанное значение переживает обновления.

Игра передаёт `install_store` как параметр существующих событий, в том числе `game_open`, и как строковый атрибут профиля AppMetrica. В «Событиях» можно смотреть пользователей `game_open` по значению параметра. Для сегментов по профилям заранее создать строковый атрибут `install_store` в настройках AppMetrica. Старые события не дополняются задним числом. Ключ AppMetrica общий, как и раньше.

Проверка на устройстве: сделать две чистые установки из магазинов, открыть игру и проверить `game_open` в AppMetrica. Отдельным тестом обновить одну из установок через другой магазин и сверить, что сохранилась первоначальная категория. Использовать тестовое устройство, чтобы не очищать основной прогресс.

## Выпуск

- База: [1.1.2 / 1102103](1.1.2-1102103/README.md).
- Релизная нумерация: `GITHUB_RUN_NUMBER=101` при `SEEDS_BUILD_FLAVOR=release` для версии 1.1.3. Подставить штатную production-конфигурацию через `scripts/configure-android.mjs`, оптимизированный APK собрать задачей `assembleRelease` и подписать прежним ключом.
- [Политика конфиденциальности для этой версии](../../store/PRIVACY.md).
- [Android о межмагазинных обновлениях](https://developer.android.com/google/play/app-updates).
- [AppMetrica о пользовательских атрибутах](https://appmetrica.yandex.com/docs/ru/data-collection/about-profiles).
