## Конфигурация и материалы

- Demo выключено. Все четыре клиентских параметра присутствуют; три боевых рекламных блока различны и имеют формат live ID. Значения не публиковались. Store workflow отказывает при demo или неполной конфигурации.
- Иконка магазина, launcher PNG и заставка используют выбранную композицию с плитками 3 и 7 и семечкой на бирюзовом градиенте. Adaptive artwork имеет дополнительный запас градиента для масок Android; шаблонный Capacitor splash не используется. Скриншоты пока сохранены прежними: их оформление и количество будут изменены отдельным шагом.
- Android backup и cleartext выключены; камера, микрофон, контакты, файлы и координаты не запрашиваются. Геолокация AppMetrica отключена. Сохранения остаются в группе CapacitorStorage.
- В настройках есть читаемый без сети экран «О данных», полная политика и контакт. Заголовок проверен на ширине 320 px: первоначальное обрезание устранено.
- `store/` содержит описание, политику, сведения о данных SDK, публичный сертификат и порядок загрузки. SDK учтены, заявления «данные не собираются» нет.
- Магазинный комплект: непрозрачная иконка 512×512, 5 изображений 1080×1920 для телефона, 3 изображения 1920×1080 для планшета. Визуально просмотрены, размеры/вес/ошибки рендера проверены. Классика показывает настоящее стартовое поле 1–19; баночки и отметки задач демонстрируют достижимый прогресс. Это production-веб-интерфейс, не имитация рекламных креативов или скриншоты SDK.

## Проверки

Успешны: 45 модульных тестов, 2 модельных сценария, 94 штатных + 15 дополнительных браузерных сценариев, 16 сценариев Java-моста. Android debug и оптимизированный release, web и Yandex draft собраны. Все 10 веб-файлов совпадают с содержимым нового APK. Уточнение проверки немедленного reload и подробности R8 — в `1.0.0-size-optimization.md`.

На Android 35 эмуляторе оптимизированный release-payload прошёл 11/11: запуск без сети, пропуск обучения/классика, удаление пары, отмена, сохранение 26 оставшихся цифр после force-stop и запуска, поворот, конфиденциальность; дополнительно — нативная инициализация монетизации, списание бесплатных подсказок, отсутствие награды за недоступное видео и сохранение баланса после force-stop. Результат и снимки актуальной оптимизации — в `1.0.0-evidence/size-optimization/`. Эмулятор временно использует CI-сертификат; доставляемый APK отдельно проверен с постоянной подписью.

В ранней попытке UiAutomation потерял Binder-соединение после перезапуска (Bad file descriptor). Исправлено повторное получение hierarchy; проверки состояния игры не ослаблялись. Финальный полный релизный прогон успешен. При просмотре настоящего Android-снимка найден и устранён длинный заголовок; после этого APK пересобран и повторно проверен.

## Следующий шаг и границы

APK и комплект готовы к загрузке в карточку RuStore; отправка на модерацию ещё не выполнялась. Перед модерацией остаётся физический Android-прогон live fill, награды за видео, возврата из рекламы/фона, аудиофокуса и поступления событий в кабинеты. Офлайн-эмулятор намеренно не создаёт реальные показы. Серверная привязка/одобрение рекламных блоков не подтверждается одним наличием ID в APK.

Первый выпуск рассчитан на Россию; возрастная маркировка заполняется по анкете с учётом сторонней рекламы. Yandex output остаётся черновиком, iOS не является подписанным магазинным выпуском.
