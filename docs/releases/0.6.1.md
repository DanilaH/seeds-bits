# 0.6.1 — исправления независимого аудита

Runtime: `8214d880d92ae7c4a227770f7aad68c45197a5d1`.

CI: https://github.com/DanilaH/seeds-bits/actions/runs/39556789120

Исправляет F01–F07 из `../audit-0.6.0/REPORT.md` и уплотняет историю подсказок (F08).

- Android фиксирует прогресс и настройки одним проверяемым `SharedPreferences.commit()` в прежней группе `CapacitorStorage`. Удаление квитанции следует за успешным долговечным сохранением. Отказ commit отклоняет Promise; отказ acknowledgment также сообщается вызывающему коду. Повтор сохранения повторно обрабатывает pending-квитанцию без второго начисления или просмотра. Ошибка, уже возникшая при открытом предложении видео, закрывает его и возвращает доступ к сохранению.
- Выдача награды привязана к конкретному показу, независимо от очистки pending token. Старые callbacks не завершают следующий показ и не создают новую награду.
- Пауза вычисляется совместно из native foreground, document visibility, паузы платформы, fullscreen и подготовки/сохранения награды. Back, меню и перезапуск закрыты на время reward transition. Сообщение о закрытом/недоступном видео остаётся после возобновления интерфейса.
- Последняя геометрия и желаемая видимость баннера повторно применяются на UI thread после SDK initialization. События снятого экземпляра баннера игнорируются; поворот сбрасывает устаревшую геометрию.
- Повреждённые поля подсказок и квитанций восстанавливаются отдельно, с уведомлением. Исправные счётчики, попытки, квитанции и поля сохраняются. Некорректный отдельный ключ сохраняет уже потраченный кредит, вместо выдачи бесплатного повтора.
- SHA-256 ключи длиной 67 символов заменяют копию поля в каждом раскрытии. Старые ключи мигрируют при чтении; повтор той же подсказки остаётся бесплатным. Истории отмены не сокращаются. На прежнем профиле из 100 тетрадей/6 830 раскрытий: 2 867 159 → 826 528 символов (−71,2%).

## Границы

APK остаётся обновляемой тестовой сборкой с прежними package/signing, demo-рекламой и включённым debug. Конфигурация live-блоков и AppMetrica сохраняется. На физическом Android ещё нужны настоящие показы, доставка событий в кабинет, аудиофокус, вырезы/системная навигация и замеры commit на слабом устройстве. Production package/signing, магазинная карточка и остальные релизные задачи этой версией не объявляются завершёнными.
