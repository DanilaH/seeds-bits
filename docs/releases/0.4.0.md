# 0.4.0 — локальный прогресс и продолжение

- Следующая непройденная задача тетради, с возвратом к пропущенным.
- Следующий доступный дейлик: вперёд до сегодня, затем назад к пропущенным. Будущие дни закрыты.
- Экран «Мой прогресс»: уникальные задачи, новые завершённые партии и завершения без подсказок.
- Необязательный meta v1 внутри прежнего progress v2: текущая попытка имеет UUID и флаг завершения. Повтор создаёт новую попытку; undo/re-win и перезапуск не дублируют результат. История всех попыток не накапливается; счётчики локальные, облачный merge не реализован.
- Миграция сохраняет партии, историю отмены, подсказки, done и трофеи. Старые победы не выдаются за новую статистику. Старое время не восстанавливается и не показывается.
- Пороги наград остаются 7/14/полный месяц. Повышение показывается только при новом ранге.
- Главное меню показывает прогресс тетради и состояние сегодняшней задачи; календарь открывается отдельно.
- Дата обновляется во время работы и при возврате; дата начатой задачи остаётся прежней.
- Переход с результата ждёт сохранения, при сбое остаётся на результате с повтором записи.

Проверки: модульные сценарии миграции, повторов, дедупликации, next-task, февраля и порогов; браузерные сценарии undo/re-win/reload, ошибок записи, полуночи, малых экранов и увеличенного текста; полный существующий набор регрессий. Итоговые числа и Android-артефакт фиксируются после CI.

Ограничения: физическая установка обновления на Android, убийство native-процесса, системные шрифты и вибрация требуют устройства. Облако, аккаунты, реклама и активное время не входят в этот выпуск.
