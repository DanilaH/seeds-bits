# Семечки 1.1.1

- Продолжение тетради возвращает к задаче, над которой вы работали.
- Перезапуск партии теперь находится в меню рядом с продолжением.
- Кнопка «Назад» остаётся на экране при прокрутке длинных разделов.
- На экране результата видно, какая задача откроется дальше: сегодняшняя или из архива, с датой.
- Исправлено зависание при запросе разрешения на уведомления Android.
- Улучшены меню на планшете, управление при крупном шрифте и сообщения о восстановлении сохранения.
- После выхода из первого обучения выбранная задача сохраняется и открывается при следующем запуске.
