## Delivered behavior

- Notebook covers use one accent, a single selected border/fill, numeric progress and a small progress bar. Filters retain their state and keyboard focus; empty filtered chapters have an explicit reset action. A compact header and denser layout expose tasks sooner.
- Navigation remembers its origin, scroll and focused control. Notebook/jar shortcuts opened during play return to play. A month opened from the collection returns to that collection. Privacy returns to settings. Cancelling an in-game restart returns directly to the preserved board.
- Home has three game modes and one progress entry. Other days are a secondary action near the daily mode. Resume includes the current mode and remaining digits.
- Progress uses accurate task/day labels and a next-jar goal. Collection separates jars from monthly trophies using tabs. Explanations of accounting rules live in expandable details.
- Calendar has an immediate today action, one compact month header with arrows, and an expandable year/month picker. The 320px layout gives days at least 44px targets without hiding past dates or enabling future dates.
- A shared light/dark palette, type scale, button targets, SVG navigation icons and header layout replace decorative color variations and double outlines. Selected digits and hinted pairs use distinct shapes. Main jar HUD retains percentage and number; detailed counts remain accessible and in the collection.
- Short fields keep feedback nearby and retain a usable viewport. The repeated basic rule disappears after the first few moves. Existing contextual rule, no-pair, invalid-move, save-error and recovery messages remain available.
- Large landscape tablets use a wider board and a separate control column, beyond the previous height-limited phone layout. Safe areas and native ad reservation remain in place. Sound, seed flights, undo, content and save formats are retained.

## Verification

First review found a too-short viewport on a sparse board and a clipped tablet hint-jump hit target. Both were repaired. Screenshot review also found a title/back collision with enlarged text; headers now use a real grid, and the browser test checks text bounds against back/close controls.

The calendar test now focuses the picker before checking that re-rendering preserves its focus. The old dead-end cancellation test now asserts the intended direct return to the board and continues to verify undo recovery.

Final standard browser result: passed. 45 unit tests, 2 model scenarios, 15 advertising/lifecycle regressions and 99 browser cases including 5 new UI scenarios and screenshots across 320×568, 390×844, 568×320 and 1280×800, light/dark and enlarged type/reduced motion.
