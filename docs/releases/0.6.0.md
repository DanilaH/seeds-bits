Adds Android SDK integration, native adaptive sticky banner, interstitials on the saved result-to-next-party transition, rewarded hints, safe-area-aware placement and AppMetrica. GitHub config supports both Actions secrets and variables; all four configured fields were found and values were not logged.

Three free hint reveals per attempt; repeats of the same board/pair are free. Video is explicitly opt-in and grants three hints. A native receipt is persisted, deduplicated into the game save, then acknowledged. Failed saves, duplicate callbacks, restart recovery and missing ads are covered. Rewarded views defer interstitials for three minutes; the initial session also has a three-minute grace period. The native cooldown persists across restarts. No daily cap.

The banner reserves a stable slot and uses the SDK refresh, with no manual recurring reload timer. It is hidden in landscape, short portrait screens, tutorials, menus, background and fullscreen display. CSS reads Capacitor's injected safe-area variables with browser env fallbacks; changes to these values reposition the native view. Full-screen ads block game input and sound. A failed load does not automatically open an ad later.

Game starts are counted on first play once per saved attempt, separate from opening/resuming the game UI. AppMetrica events include mode, hint/ad actions and errors, with a test flag. No board contents or digit-by-digit custom events are transmitted. SDK location tracking is disabled.
