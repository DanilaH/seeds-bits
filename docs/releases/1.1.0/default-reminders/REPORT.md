После отказа настройка выключается, запрос не повторяется автоматически после перезапуска. Нативная форма оценки рядом не показывается, ближайшая межстраничка пропускается.

Переключатель показывает настройку игрока, пояснение рядом отдельно сообщает об ожидающем разрешении или системной блокировке.
