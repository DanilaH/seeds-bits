## Исправления

- Тетради, первый запуск. В коротком альбоме подсказкам о пропусках и переходе через край выделена отдельная колонка. Её ширина и положение поля сохраняются при смене команды. Воспроизведение: решить 6+4 и 9+1 в первой задаче, затем убрать две тройки.
- Тетради, победа. Длинные заголовки завершения страницы и тетради переносятся и помещаются при ширине 320 CSS px и 200%.
- Обычное поле. Название баночки в шапке переносится целиком. В укороченной шапке под рекламу существующая иконка банки и процент остаются доступными.
- Классика, победа. Размер текста рассчитывается относительно исходного CSS-размера. При ширине до 350 CSS px кнопке «Сложнее» выделено больше места. Подписи могут переноситься, если строка всё равно слишком узкая.
