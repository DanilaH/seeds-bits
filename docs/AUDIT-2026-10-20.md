# Семечки 0.3.0 — второй независимый прогон

Проверены исходники `6df0576026829c253ca5e4536aef6f08a91e9c91` (HEAD с отчётом: `9d157d25d2d7a666247e6df3fbae43f7ea58e046`) и содержимое выданной APK. Игровой код в этом прогоне не менялся.

## Вывод

Критических поломок обычного игрового цикла не обнаружено. Все 25 прежних браузерных сценариев снова прошли. Новые сценарии выявили два воспроизводимых UX/синхронизационных дефекта и ограничение подсказок на двух будущих ежедневных задачах. Готовность магазина этим прогоном не подтверждается: физического Android здесь нет.

## Находки

| ID | Приоритет | Что произошло | Что сделать |
|---|---|---|---|
| B01 | Средний | При повреждённом progress.v2 открывается новая партия, предупреждение находится в скрытой за меню игровой области. В меню человек видит обычное «Играть». По возможности оставить резервную копию повреждённых данных. |
| B02 | Низкий, браузер | Открыть две вкладки одной партии. В первой включить тёмную тему, во второй — звук. В сохранённых настройках тема возвращается к светлой. Не блокировать всю игру из-за смены темы. |
| B03 | Низкий сейчас; будущее ограничение | Из 730 ежедневных задач 728 пройдены только проверенными подсказками. В начальных позициях 19.03.2028 и 16.08.2028 поиск исчерпывает 50 000 узлов. В браузере первая задача блокирует очередь событий на 1301 мс, затем предлагает отменить предыдущий ход, хотя ходов нет и «Отмена» выключена. | Для начальной позиции использовать уже известное конструктивное решение; для других позиций убрать тяжёлый поиск с главного потока и сделать честный fallback без недоступного действия. |

B03 не означает, что эти две задачи нерешаемы: генератор сохраняет конструктивное решение. Лимит поиска корректно возвращает unknown, а не ложный тупик. Даты в будущем проверены с фиксированными часами, не открывались пользователю раньше времени. Для 100 альтернативных позиций после первого хода в задачах 1–20 октября 2026 unknown не получен; максимальное измеренное время — 34,3 мс. Это не доказательство для всех возможных веток.

## Проверки и доказательства

- Отдельная геометрическая реализация правил: 1200 детерминированных случайных досок, сравнение допустимости пар и списка подсказок.
- Независимый исчерпывающий перебор: 250 маленьких досок, сравнение решаемости и проверка предлагаемого хода.
- 16 существующих модульных тестов + 2 независимых проверки: 18/18.
- 730 ежедневных задач с новым экземпляром решателя для каждой даты: 728 полностью решены подсказками, 2 возвращают unknown. Данные в `audit-2026-10-20/daily-census.json`.
- Браузер: полный прогон 32 сценариев — 31 прошёл, B01 воспроизведён. Ещё три целевые проверки — две прошли, B02 воспроизведён. Итого 35 запусков, 33 прошли, 2 выявили ошибки; B03 намеренно проверяет наблюдаемый fallback, а не выдаёт его за исправление.
- Пройдены: одновременные нажатия pair/undo/menu/mode/add, отмена победного хода с перезагрузкой, историческая отметка завершения, два схлопывания с клавиатуры, reduced motion, 320 px и удвоенный корневой размер шрифта, тупик без истории, старый конфликт сохранений между вкладками.
- Все 24 задачи тетради снова пройдены через UI по подсказкам. Длинная партия на 1800 клеток, 30 пар, переключение, прокрутка, reload и undo прошла за 11,9 с в этой среде.
- Восемь файлов web-части внутри выданной APK побайтно совпали с новой сборкой проверенных исходников; см. `apk-assets.json`. Это проверка содержимого APK, не запуск нативного приложения.

Скриншоты `corrupt-save-menu.png` и `hard-daily.png` подтверждают видимые состояния. Полные результаты браузера сохранены рядом. Измерения времени относятся к среде проверки, не являются FPS или бенчмарком телефона.

## UI и ощущение игры

Повторного исчезновения клеток при выборе, потери фокуса после удаления пары и прежнего зависания длинного поля не получено. Уменьшенная анимация действительно отключает движение. Перестраивать оформление по этому прогону оснований нет. Самое полезное улучшение ощущения — предсказуемая помощь и видимая обратная связь при проблемах с сохранением.

Горизонтальное обучение на низком экране доступно через прокрутку всего экрана; это рабочий компромисс, а не размещение всех кнопок одновременно. Удвоенный корневой размер шрифта в браузере не равнозначен проверке системного масштабирования Android. Нативные Back/background/kill, вибрация, звук, установка/обновление и расход батареи на устройстве не проверены.

## Повторить

Из корня репозитория:

```sh
npx vitest run --config scripts/audit-2026-10-20/vitest.config.ts
npx playwright test --config scripts/audit-2026-10-20/playwright.config.ts
```

Второй запуск намеренно содержит две падающие проверки B01/B02. Они вынесены в отдельный аудит, не скрыты через skip/expected-failure и не добавлены в обычный релизный gate. Для альтернативного Chromium можно задать `SEEDS_CHROMIUM`.
