# Семечки 0.3.1 — исправления второго аудита

Основание: `AUDIT-2026-10-20.md`, B01–B03.

- B01: предупреждение о нечитаемом/частично повреждённом прогрессе вынесено в отдельную панель. Она следует за меню и игрой, остаётся после выбора цифры и закрывается явной кнопкой «Понятно». Если запись доступна, исходная строка сохраняется в `seeds-bits.progress.v2.recovery` перед продолжением; это последняя резервная копия, не обещание автоматического восстановления повреждённых данных.
- B02: запись настроек сливает только изменённые пользователем поля с последней сохранённой версией под существующей блокировкой. Неизменённая тема/звук больше не берутся из устаревшей вкладки. Событие storage обновляет интерфейс других вкладок, сохраняя ещё не записанные локальные изменения. Проверка конфликта прогресса остаётся.
- B03: проверенное конструктивное решение заполняет кеш начальной позиции и всех позиций на этом пути. Неверный переданный путь не считается доказательством. Поиск произвольной позиции и точки восстановления выполняется в Web Worker с общим таймаутом 2,5 с. Запоздавшие результаты после выбора клетки, смены режима, меню или паузы не применяются. При недоступном worker игра продолжает работать, сообщение не предлагает отмену при пустой истории.

Новые регрессии: `e2e/audit-fixes.spec.ts`, дополнения `tests/advice.test.ts`. Все 730 исходных ежедневных задач с 01.10.2026 проверяются до конца по конструктивным подсказкам с нулевым бюджетом поиска. Это не обещание мгновенного решения каждой произвольной позиции: для них сохраняется честный unknown/fallback.

Исторические данные и воспроизведения второго аудита оставлены неизменными. Они описывают 0.3.0; текущие исправления проверяются обычным release gate.

Android: пакет `com.seedsbits.game.preview`, тот же приватный ключ, что у выданной 0.3.0. Новая APK предназначена для обновления «Семечки · тест» поверх. Старые APK пакета `com.seedsbits.game` не заменяются. Физическое устройство, системное масштабирование, звук/вибрация и нативный жизненный цикл здесь не проверены.
