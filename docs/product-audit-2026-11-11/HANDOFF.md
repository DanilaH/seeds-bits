# Handoff — аудит и приёмка «Семечек»

Приложение **не опубликовано в RuStore и не отправлено на модерацию**. В этом задании публикация и изменение production-рекламных ID/частот не выполнялись.

Код игры: **1.1.2**, `160da8c79fd013f25a64607b7338ed6a65131942`. Ветка `qa/product-audit-20261111`, [PR #2](https://github.com/DanilaH/seeds-bits/pull/2). Последующие изменения касаются CI, средств проверки и материалов; деревья `src/native` совпадают с проверенным исходником.

[Полный аудит](../PRODUCT_AUDIT_2026-11-11.md) · [скриншоты и GIF](README.md) · [результаты](acceptance.json) · [проверка на телефоне](PHONE_CHECK.md).

## Реализовано

- Завершения и награды отправляются в AppMetrica после успешной записи результата. Ограниченный журнал сохраняет `attempt`, `event_id`, исходное время и запуск. Восстановленная очередь ждёт подтверждённой записи, а не одного чтения process cache Android.
- Ошибка reminder sync не маскируется под отказ уже завершённой записи. Повтор rewarded receipt не начисляет подсказки дважды. Wire v5 / meta v2 и старый прогресс сохранены.
- Release/preview, версия/сборка и ad mode разделены; preview не берёт production key. Добавлены ранние сохраняемые milestones и fresh/legacy когорты без синтеза старых действий.
- После обучения можно выбрать короткую задачу. Объяснены допустимая пара и край строки; CTA явно обозначает следующую страницу. Исправлены крупный текст и поздняя сводная запись web-настроек второй вкладкой.
- Native OCR больше не зависит от недоступных Ubuntu mirrors. Официальные Tesseract/Leptonica/tessdata закреплены commit SHA; OCR получает lossless RGB PNM из сохранённых PNG. Все исходные assertions сохранены. OCR не входит в APK. Старые workflow с системным Tesseract сохраняют PNG-режим, новый путь явно включает PNM.

## Аналитика и QA

Ранний native UX ошибочно имел сеть, хотя был назван offline. Настоящий баннер подтверждён кадрами. Возможный приём AppMetrica сервером не установлен; события в кабинете не удалялись. Исключить **1102004–1102014** из анализа игроков: [исторический карантин](analytics-quarantine.json). Старые исследовательские CSV этим не объявляются QA-трафиком.

**1102015 теперь зарезервирован для ручной приёмки.** Его offline-эмулятор сеть не получал; предстоящая установка владельца может отправлять QA-события. Перед магазинной публикацией нужен отдельный build number, чтобы исключение этой QA-сборки не отрезало органических пользователей. Самостоятельная серверная проверка AppMetrica/VK в этом задании не проведена.

## Что остаётся

1. Телефон: реальный звук/вибрация, live banner/rewarded/interstitial без VPN, уведомления под ограничениями производителя, RuStore review flow и установка поверх старой версии с production-сертификатом. В тесном landscape/тексте 150% проверить заметность прокрутки боковых действий.
2. Несколько новых игроков по 10–15 минут: понимание правил и подсказки, заметность короткого маршрута, первая самостоятельная пара/победа, смысл банки/страницы/медали, добровольность рекламы. Наблюдения не проведены; автоматические известные решения не измеряют удовольствие.
3. Кабинет AppMetrica: фактический приём schema 2 правильным счётчиком, исключение QA, затем построчная выгрузка для попыточной воронки. Источник старых CSV неизвестен; самих CSV в переданном архиве нет. VK attribution/postbacks не проверены.
4. Историческая причина трёх save_error не доказана. Реальное обесточивание дискового commit полностью не воспроизведено. Bridge подтверждает локальный SDK enqueue, не сервер; crash gap может повторить event_id, нужна дедупликация. Длительная недоступность ограниченного журнала может вытеснить старую необязательную телеметрию, не игровой прогресс.

Измеримые продуктовые гипотезы — в аудите. Рост удержания и интересность всех 2400 задач не доказаны. Большая мета-система и скрытая адаптация сложности не добавлялись.
