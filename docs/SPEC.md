# Семечки — согласованное ТЗ, 15 октября 2026

## Платформы и стек
Android/RuStore, Яндекс Игры, потенциально iOS. Один проект TypeScript + Vite + HTML/CSS/SVG; Capacitor для Android/iOS. Без React, игрового движка и самодельного фреймворка. Платформенные API изолированы от правил.

## Правила 0.1
9 столбцов, значения 1–9, ноль означает пустую логическую клетку. Старт — посимвольная запись 1–19 с исключением нуля (28 цифр). Допустимы одинаковые цифры или сумма 10. Соединение: строка, столбец, диагональ 45 градусов, если промежутки пусты; дополнительно соседние занятые элементы в порядке чтения, даже через границу строки. Если возможны оба пути, показывается прямой.
После удаления полностью пустые строки исчезают, другие клетки внутри строки не сдвигаются. Добавление только при отсутствии пар: копируются все оставшиеся цифры и дописываются после конца логического массива, включая его пустой хвост; визуальные добивки неполной строки не входят в массив. Победа при пустом поле. Нет поражения из-за отсутствия пар, таймера, повторного состояния или технического предела.

## UX
Три подписанные кнопки: Отмена, Подсказка, Добавить N. Повторное нажатие по выбранной цифре или на пустую клетку снимает выделение. Недопустимая вторая цифра становится выбранной; показывается причина. Подсказка показывает допустимую пару и путь, не обещает победу. Отмена возвращает точное поле, счётчики и прокрутку, история переживает перезапуск. Во время изменения поля ввод блокируется.
Учебные позиции: равенство, сумма, пустоты, диагональ, перенос строки, добавление/отмена. Пропуск и повторный запуск доступны. Главное меню ориентировано на продолжение партии. Новая партия требует подтверждения, если вызывается из меню.

## Визуальное направление
Чистая бумажная сетка без текстуры, печатные цифры, спокойный синий акцент. Светлая и тёмная темы. Без постоянных следов удалённых цифр, монет, градиентов и декоративных карточек. Поле прокручивается; столбцы не меняются при повороте устройства. Первое оформление предварительное, его нужно проверить на реальном телефоне.

## После прототипа
Проверить настоящий UX, размер касаний, длинные поля и сохранения на Android/iOS. Затем реклама: зарезервированный баннер отдельно от кнопок, межстраничка только после результата при явном продолжении, без блокировки игры при ошибке сети. Первый урок без полноэкранной рекламы. Не превращать добавление/отмену в платные ресурсы.
Короткие поля — отдельный эксперимент, не обязательство MVP. Каталог, ежедневки, валюта, облако и авторизация отложены. Коммерческий спрос и доходность собственного приложения не подтверждены.
